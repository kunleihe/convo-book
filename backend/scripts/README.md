# Scripts Directory

This directory contains utility scripts for the convo-book project.

## Available Scripts

### TTS (Text-to-Speech)
- **Location**: `tts/`
- **Purpose**: Generate audio files for book questions using OpenAI's TTS API
- **Usage**: See `tts/README_TTS.md` for detailed instructions

## Running Scripts

All scripts should be run from their respective subdirectories to ensure proper path resolution.

Example:
```bash
cd backend/scripts/tts
./generate_question_audio.sh
```
